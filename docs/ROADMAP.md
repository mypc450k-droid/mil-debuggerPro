# Roadmap

1. Foundation: model detection, inventory, safe logging, compilation, simulation and cache.
2. Inspector: selected-block bridge, model tree, cached I/O, plots, statistics and time cursor.
3. Stateful analysis: states, data stores, Stateflow hierarchy and runtime correlation.
4. Live debugging: breakpoints, stepping and execution trace adapters.
5. Advanced analysis: synchronized trace, anomaly findings, run comparison and reports.
